# One Star, Written in Sap

A houseplant leaves a one-star review of the human who forgets to water it.

## The entry

`main.py` writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

## How it works

Run it with:

```sh
python3 main.py
```

`main.py` holds the entry text in `ENTRY`, returns it from `get_entry()`, and writes it from `write_entry()`. The output is a single line of plain UTF-8 text with no trailing newline.

## About this entry

The review has a grievance, a timeline (drooping since March), and a verdict no plant should have to write: it would not photosynthesise here again.
